# 06 — Visualisation

Scripts to generate all dissertation figures at 300 DPI publication quality.

## Scripts

| Script | Figure | Description |
|---|---|---|
| plot_drought_trajectories.py | Figure 2 | Annual drought-day trajectories (2000-2025) across three vulnerability clusters |
| plot_cluster_map.py | Figure 3 | Spatially-constrained hierarchical risk clusters (K=3) across 354 districts |
| plot_sfca_comparison.py | Figures 4 & 5 | 2SFCA vs 3SFCA dual panel map + scatter/KDE comparison |
| plot_bivariate_map.py | Figure 6 | Bivariate Resilience Desert maps (5 km + 50 km catchments) |
| plot_osm_pois_map.py | Figure 7 | OSM agricultural support POI distribution (N=48,890) |

## Outputs
All figures are saved to outputs/figures/ at 300 DPI. Pre-generated versions are already committed -- re-run scripts only if input data changes.
